Procedure de changement de mot de passe

1. Connectez-vous à votre compte en utilisant les informations fournies ci-dessus sur le portail (https://portail.purs.gouv.tg/).
2. Une fois connecté, accédez à la section "Utilisateur".
3. Cliquez sur l'option "Modifier le mot de passe" (patientez quelques secondes pour qu'on vous envoie un code de confirmation par mail sur votre adresse email, et qu'une fenetre s'ouvre).
4. Sur la fenetre qui s'ouvre, entrez le code de confirmation envoyé par mail, ensuite, entrez votre mot de passe actuel, puis choisissez un nouveau mot de passe sécurisé et confirmez-le.
5. Enregistrez les modifications et assurez-vous de vous souvenir de votre nouveau mot de passe pour vos futures connexions.
